## Present behavior observed in this checkout

The collection contains ten authored task programs, linked program/body inspection, explicit task runs, fresh executed reproductions and two complete-source encodings. Its prepared scenarios change source-encoded inputs. Collection recovery controls check recovered source by execution; they must not inherit the passive-recovery wording used elsewhere.

Create accepts explicit supported recipes or typed plans. An optional configured service proposes broader interpretations for compiler validation. Building, body viewing and source recovery are passive. Run evaluates the task and emits source; Create verified copy runs a fresh instance. Original wording and interpretation are retained in a companion artifact, rather than guaranteed inside legacy constructor source.

The Ranch starts with ten local residents and disabled gestures, participation and social time. Social commands can produce reciprocal proposals. Preview prepares a complete source candidate. Library admission saves a program without a meadow birth; world admission consumes the relevant proposal and creates a nursery resident. Neither admission runs a task. Nursery time controls social eligibility; it is not evidence of task learning or success. Source parent hashes remain claims; session derivations retain construction evidence. Data belongs to the current tab.

The Agent SDK provides the current sixteen operations, TypeScript Runtime, MCP and A2A adapters. Reviewed research identifies missing reusable SDK run bindings, session restoration and consistent adapter output contracts. QDL and the downloadable package remain experimental. All current action receipts are simulated locally. The City walkthrough uses public character art with an explicitly authored local task; it is not a captured agent thought or live connection.

## Outcomes and uncertainty across surfaces

## Integration review checklist

1. All four title/hero combinations retain exact **Living Thoughts** and immediate declared-task context. Navigation consistently uses Collection, Create, Ranch, and Agent SDK.
2. The first visitor can explore a real task, follow an operation to its body, press a plainly labeled Run, and read a local result. The lifeform language remains attached to form and family.
3. Collection recovery and reproduction retain their execution disclosure. Create/SDK passive recovery retains its passive disclosure. Similar-looking controls must not hide different behavior.
4. Every Ranch event reports the actual stage: invitation, meeting, proposal, preview, admission, then any explicit Run. Nursery membership and source lineage do not announce task success.
5. Pending, unknown, missing, failed, skipped and completed remain separate. Only implemented observable states receive live labels.
6. Source export preserves executable source; companion export preserves original wording where supplied; future session export requires its own gate. The source genome is never presented as a screenshot decoder or a complete memory backup.
7. Copy integration includes dynamic JavaScript strings as well as HTML defaults. Verify desktop/mobile reading order and screen-reader status updates; a static HTML replacement alone can be overwritten on first interaction.
8. The QDL v1 work plan remains a candidate plan until conformance, compatibility, formal-scope, security, packaged-consumer and browser/release gates pass. Formal proof language cites its scoped evidence rather than guaranteeing all program behavior.
