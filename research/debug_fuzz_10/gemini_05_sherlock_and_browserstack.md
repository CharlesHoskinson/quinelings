## 1. Executive Summary

| Target Surface | Defect / Symptom | Exact Root Cause | Severity | Status / Fix |
| :--- | :--- | :--- | :--- | :--- |
| **`index.html` (`src/designers/designer8_quineling.js`)** | `THREE.AttributeNode: Vertex attribute "uv" not found on geometry.` + invisible 8,192-point `WovenBody_TissueCloud` | `tissueGeom` (`designer8_quineling.js:756`) only defines `position` and `color` attributes, while `tissueMat` (`:762`) is a `THREE.PointsMaterial` with `map: getTissueSpriteTexture()`. Under `THREE.WebGPURenderer` (`three/webgpu` v0.175.0), `PointsMaterial` compiles to `PointsNodeMaterial`, whose `MaterialNode.COLOR` samples `material.map` using `TextureNode.getDefaultUV() -> uv(0) -> AttributeNode('uv', 'vec2')`. Missing `uv` logs the warning and falls back to `vec2(0.0, 0.0)`, where `getTissueSpriteTexture()` is `rgba(0,0,0,0)` (transparent black), zeroing out all 8,192 tissue points! | **P0 Visual & Warning** | Add `uv` attribute (`fill(0.5)`) to `tissueGeom`, remove `map` from `tissueMat`, and add `uv` attributes to `sdkRibbonGeom` (`:835`) and `tendrilGeom` (`:951`). |
| **`motion.html` & `slideshow.html`** | Canvas stuck at `300×150` with `0` bright pixels upon load | `GRAPHS.tideglass` (`motion.html:488`, `slideshow.html:503`) uses `{ id: 's2', op: 'window', inputs: ['s0'] }`. `'window'` is not in `Chroma.ROLE_MAP` (`src/engine/quinelingsSdk.js:463`), causing `Chroma.colorFor()` to throw `Error: Unknown chroma operation window` during top-level module evaluation before `resize()` and `requestAnimationFrame()` run. | **P0 Blocker** | Replace `op: 'window'` with canonical `Q.OPS` in `motion.html` and `slideshow.html`, add fail-soft `buildChromaPalette`, and call `resize()` first. |
| **`test/browserstack_quinelings_verify.mjs`** | Unified Local Playwright + BrowserStack Automate verification across `motion.html`, `slideshow.html`, and `index.html` | Automated verification across all 3 pages and BrowserStack Automate cloud browsers. | **P1 Verification** | Complete `test/browserstack_quinelings_verify.mjs` script engineered and executed. |
