## What distinguishes the project

The arithmetic, BFS, scheduling, Boolean predicates and record filtering are ordinary deterministic algorithms. A sum becoming a creature is not itself a new algorithm. Quotation-based self-emission is a mechanism the site can demonstrate without claiming its invention. The interesting engineering combination is one source artifact that commits a typed finite task, public declarations, anatomy ownership, deterministic gesture, bounded effects policy and a pinned runtime registry, and survives self-emission and two recoverable encodings.

A normal calculator can show 4 becoming 7; a dataflow debugger can show the contributing nodes. QDL adds a source-owned visual body, a separate exact source identity, explicit recovered-source admission, and reproduction with retained bindings. Those additional claims need their own observations. Hash equality establishes identity of represented bytes, not physical source authenticity. The body is a lossy visual summary; source/genome identity is the exact channel.

The mathematical content is clearest when exposed as testable properties: finite DAG order; symbolic unit/type checks and runtime refinements; deterministic tie policies; conservative unknown/conflict handling; inclusive boundaries; atomic occurrence publication; bounded harmonic gestures; source-preserving view transitions. These do not establish biological life or inference hidden inside a portrait. The complete mathematical body is useful as an inspectable index into an authored program.

A defensible homepage sentence: “Run ten small typed programs, follow recorded values through their bodies, and recover the exact source that produced them.” Explain the same source with a changed result before presenting a source-changing body experiment.

## Three experiments that make the representation credible

1. **Observation changes.** Compile water-total once. Run [1.5,2,0.5], then [1.5,5,0.5]. Show same sourceHash, changed inputHash, liters4→7/count3→3, unchanged node/edge/owner sets and unchanged fixed-phase geometry. The zero geometry displacement is a positive result: anatomy belongs to source, while recorded values belong to an invocation. A recorded overlay may change independently.
2. **Source changes.** Copy water-total intent to a newly named variant and add a source constant cap=5, a `clamp` stage between total and summary, and retain count. Declare matching liter units and refinements; update the public declaration/task references before compilation. Use readings[1.5,5,0.5] for both. Original liters7 versus capped liters5; changed node/edge sets, source hashes and generated ownership show a real program edit. Report geometry comparisons as differing topology, with fixed phase/camera/sample budget, rather than pretending pointwise nearest indices denote the same tissue. This variant changes task semantics and generated anatomy; keep it separate from the ten frozen recipes.
3. **Gesture changes.** Play or scrub the same artifact at phase0 and phase0.25 while retaining the same run record. Show changed pose, unchanged source/input/output identity and zero new task evaluations. For a source-authored gesture variant, change a declared gesture parameter instead; demonstrate changed source with same task result. Gesture playback is an equation evaluated for presentation time.

A fourth passive proof panel can show exact emission equality, fresh admitted constructor generation, same-input fresh evaluation equality, and exact recovery of full source from both underlying codecs. Label each action separately. Passive codec recovery is not a new task run, and source verification alone does not confirm output correctness. Retain full source bytes behind an expandable panel; a short hash is a navigation aid rather than the equality test.

## Copy and interaction corrections

Current index “Change the inputs” selects a legacy fixture that changes encoded literal source. Its control help is accurate but the first-experiment wording obscures the distinction. New homepage should use QDL 1 named inputs and explicitly mark source variants. Do not mix the old ten named creatures with the new ten recipes under one unlabeled recipe count.

“From Midnight.city” and “an agent’s written task” can suggest live access or autonomous interpretation even with provenance footnotes. Put “Supplied task description → authored typed program → body” directly beside the scene. Create has constrained authoring examples and optional interpretation plumbing; build success demonstrates admitted syntax, not correctness of arbitrary prose understanding. Public thought declarations are inspectable author statements, not an LLM’s private cognition.

Ranch “Two thoughts become a family” is a metaphor. Place the actual construction rule and its seam/types next to parent selection. Preview, source admission, social proposal and explicit Run are different events. The SDK supplies integration APIs; adapter availability does not establish durable world actions or authenticated City observations.

For each recipe show four short facts: **What it computes; supplied data; exact changed intermediate; what the output authorizes locally.** Trade and gather need failed-guard summaries; evidence needs records and skip reasons; reconciliation needs attempt history; schedule needs interval lanes. Keep raw JSON available without making it the only explanation.

Use steady role colors for anatomy and a separate labeled overlay for recorded state. A trace overlay must say “recorded run”, name occurrence and node, and distinguish absent/stale/invalid values from zero/false/unknown evidence. Changes to selection or phase must not quietly execute tasks. Render actual trace values rather than independently recomputing a second unofficial result in UI code.

Make visible numeric invariance as interesting as change: craft floor plateaus, repeated-source evidence, duplicate acknowledgements, positive-hunger plateaus and noncritical schedule durations teach policy better than ten animated success badges. Provide a baseline comparison and exact selected-node value beside the portrait. Explain the causal chain in one sentence before exposing the graph and equations.
