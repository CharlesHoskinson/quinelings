# What the examples actually demonstrate

The homepage now compares two supplied input snapshots of the same QDL 1 program. It runs both through the interpreter and presents their outputs, trace values and source identities. It does not infer a task from a visitor’s private thoughts or act in Midnight.city.

## Results of the review

The ten recipes matched independently derived expected outputs. The retained release fixtures also passed. This is evidence for the inputs tested, not a proof of every admitted input. All ten graphs have paths from every node to a declared output.

The previous workspace gave input changes almost no visual consequence: water totals changed while the source-owned body and fixed-phase pixels remained identical. That is the representation’s intended boundary, but the page did not teach it. The older gallery instead rewrites literals when selecting a scenario, creating a different source artifact. The two interfaces now have distinct labels and links.

## Source edits and exact reproduction

A separately authored water program adds a clamp at five liters. On the same readings totaling seven liters, its result is five. The graph grows from four to five nodes, and ownership grows from seven to eight bands. Both bodies retain the same four-component tree; dimensions and operation anchors change. Their area-weighted sample plans differ, so indexed points are not treated as corresponding tissue. The comparison measures shared node anchors at phase zero instead. The two portraits share a camera and framing bounds, so independent auto-fitting does not conceal their changed dimensions.

The older Pulsekeeper has a genuine authoring mismatch: its reported budget literal and fixed four-attempt retry parameter are separate values. Reporting a budget of one does not enforce one attempt. The archived program is retained. A new homepage policy experiment writes the chosen cap directly into the retry operation: prepared outcomes `retry, retry, ok` exhaust cap one after one attempt and complete cap four after three. Neither program submits work.

The quine check compares the constructor’s entire emitted canonical source with its input source. Harmonic and RGB genomes are reversible encodings of those bytes. Separate decode controls perform no task evaluation. The three-generation control explicitly recovers chained source in fresh sessions and runs each copy with the retained bindings. Exact source, exact emission and equal calculation are reported separately. The drawing is a lossy portrait, not the recovery channel.

## Refusals and provenance

A typed input refusal creates no after-record. The page retains the previous complete comparison, visibly marks it historical, and hides matching-run labels. It never mixes a newly computed baseline with an older after-record. The baseline attempt still accounts for one graph evaluation; the typed refusal enters the interpreter too, so that interaction adds two interpreter requests. Malformed editor JSON is rejected before either request. Replay returns the same retained record without evaluating again.

Overflow and cyclic schedules produce failed records with diagnostics, no published outputs or effects, and only the trace nodes that finished. The pinned scheduler currently classifies its cycle diagnostic as `refinement`; its message identifies the cycle. The raw classification remains part of the retained runtime; the website now distinguishes cycle and missing-dependency failures in its presentation without changing the original record.

## Scope and limits

The algorithms are familiar: sums, unweighted breadth-first search, Boolean guards, record reconciliation and unlimited-parallel dependency scheduling. The experiment combines an executable typed task, source-owned anatomy and an exactly recoverable identity. It does not establish a new planning algorithm or biological life. Equal outputs can conceal changed trace values; different source programs can have similar or identical portraits.

Source labels are supplied data, not authenticated witnesses. Several freshness checks are caller-supplied Booleans. Hunger is a positive guard, not an optimization weight, and zero-restoration food remains eligible in the retained recipe. Schedule traversal order is not dispatch order. Runtime numbers use JavaScript floating point. Route, food and gather actions are local simulated receipts; other examples publish calculations without effects. The Ranch’s social policies remain experimental.
