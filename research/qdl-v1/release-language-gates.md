## All 31 operation policies reviewed against code

The static signatures were checked in `qdl-v1-contract.js`, the retained calculators in `kernels.js`, the seven additions in `qdl-v1-kernels.js`, and strict finite/integer wrappers in `qdl-v1.js`. Tests include the 31-op matrix without executing sample values to admit graphs. The table gives precise edge policies to retain in future conformance; it is not a new operation contract.

| Operations | Implemented policy and documentation agreement |
| --- | --- |
| `literal`, `input` | Authored constants validate against full declared type. Required named ports require exact supplied bindings; omitted values refuse, optional means explicit null. Source never changes with inputs. |
| `sum`, `mean`, `min`, `max`, `weightedMean` | Empty sum=0; other empty reductions refuse. Weighted arrays must be equal/nonempty, weights dimensionless/nonnegative and mass positive. Reduction order is left-to-right; strict wrappers reject nonfinite intermediates and relevant declared safe-integer intermediate overflow before later cancellation could hide it. Mean/division may return a fraction; inferred output refinements are erased. |
| `length`, `map` | Length counts array entries or UTF16 code units and carries count. Map square multiplies the symbolic unit by itself; multiply's authored factor is dimensionless, with unchanged unit. Finite result checks and applicable integer obligations are explicit. Empty map is empty. |
| `sort`, `dedupe`, `filter`, `compare`, `compareValues` | Homogeneous scalar sorting uses ordered own paths and stable original-order ties. Dedupe keeps first canonical key/value. Equality is canonical structural equality; ordered comparisons are compatible numbers or strings. Strings preserve code units/no normalization; numbers retain exact symbolic units. Empty collections return empty for sort/dedupe/filter. |
| `choose`, `get` | Eager alternatives; optional-null merging only, no arbitrary union. Action ancestors in alternatives refuse admission, and absent own paths can fail regardless of later branch selection. Path bounds and forbidden keys are checked statically. |
| `clamp`, `budget` | Ordered finite authored clamp interval; budget requires runtime nonnegative numbers of matching units and returns min(available,desired), remaining available-allocation. Full output refinements remain runtime obligations. |
| `action`, `report` | Action returns simulated/skipped metadata only; guard/payload cones must be pure. Publication is occurrence-atomic, and a completed action trace before a later failure is not an effect. Report maps unique safe authored labels to ordered values; zero-port report is an empty closed record. |
| `bfs`, `allocate`, `schedule` | BFS follows ordered neighbors with shortest edge-count path, bounded visited IDs and explicit blocked endpoint miss. Missing adjacency means no outgoing neighbors. Allocation is request ordered, safe nonnegative integer amounts and unique IDs. Schedule is first-ready authored job order and earliest dependency finish, allowing parallel independent jobs; cycles/missing dependencies fail. Empty allocation retains availability; empty schedule has makespan 0. |
| `consensus`, `evidence`, `evidenceFresh` | Consensus keeps first vote per source and first-seen winning choice on ties; empty choice is null/support0/acceptedfalse. Stable evidence requires authored claim and keeps first matching source+claim report; empty is unknown. Fresh evidence checks complete rows, unique IDs, inclusive time/revision and the documented claim→kind→unknown→future→stale→revision skip order; one contradictory source contributes once to each polarity, not two independent sources. |
| `retry`, `reconcile` | Retry consumes provided outcomes up to1–8, stops on ok/unknown and never submits; empty supplied history is exhausted with attempts0. Reconcile validates all supplied rows, then filters operation, deduplicates identical matching IDs and orders complete per-attempt history by sequence. Equal-sequence conflict, changed terminal receipt or attempt budget overflow fails. Unknown/pending precede met quota; confirmations count once with checked unit sum. Empty zero-requested is completed, empty positive request ready. Input order may change input identity while assessment stays equal. |
| `arithmetic`, `all`, `select` | Add/sub/min/max require equal units; mul/div/floorDiv compute exact symbolic products/quotients. Division zero refuses; floorDiv additionally requires safe nonnegative operands/positive divisor. Inferred shape does not prove bounds. Empty all=true, so a meaningful nonempty checklist requires an authored minimum. Select uses exact query fields, ordered scalar record paths and stable row ties; empty/no match returns the fully typed authored default with index null, never an invented observation. |

No documented tie, empty, overflow, units or refinement rule conflicts with the implementation reviewed. Policies such as empty retry being exhausted and validation of foreign-operation receipt rows before filtering are deliberately recorded here because they matter to callers; neither implies an unadvertised retry or permission to ignore malformed snapshots.

## Exact release action still required

`docs/QDL-V1-UPGRADES.md` supplies the right policy: retain the matching runtime, source checkout, manifest, golden sources and exact genomes; a future runtime must support that exact pin explicitly or reject `unsupported-registry`. Old-pin upgrade is reviewed inspection with its matching runtime followed by explicit construction under the target pin, new identity, separate fixture evidence and fresh keys. There is no silent fallback, implicit source rewrite or promised universal migration engine.

The current published tarball is `assets/sdk/quinelings-agent-sdk-0.0.0-experimental.tgz`, recorded SHA256 `26736a20abbc47119633864600bc67d030e6f94c21ab79333609e112819a0a82`. Existing acceptance and publication files still say candidate/pending release freeze. Merely leaving a mutable web tarball at that URL does not finish immutable retention. The release owner should retain the final matching artifacts under the intended immutable tag/release and record their exact hashes and final acceptance manifest. If package metadata changes during release, hash the new tarball and run the already-defined installed-consumer checks against that actual retained artifact. Do not regenerate source/genome goldens to hide a failed check.

That is a concrete release bookkeeping/compatibility action, not a newly discovered evaluator defect. Once it is completed, scope the stable claim to **QDL 1 at this registry pin**, deterministic bounded simulation and the tested host environments. Legacy APIs, collaboration/body presentation and shared deployment guarantees remain separately described. No npm publication, live City dispatch, arbitrary English interpretation, universal factual truth, durable authentication or complete-JavaScript proof is needed or implied for this language release.
