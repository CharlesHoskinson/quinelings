# Quineling ranch: converged experimental candidate

Status: candidate for nine independent design audits before implementation, 2026-10-04. All ten brainstorm reports in research/ranch have been read. No ranch behavior or new proof is claimed here. Existing QDL remains experimental; the existing qdl:1 marker does not freeze the language.

## 1. What the ranch delivers

A dedicated ranch.html presents many distinct, source-backed residents meeting in a luminous mathematical garden, forming reciprocal pairings, merging programs and creating independently recoverable offspring. The library exposes the same construction and lifecycle operations to agents through TypeScript, MCP and A2A. Thought → actual typed operation → owned tissue remains inspectable. Every child carries a complete task, anatomy, gesture and chroma in its constructor source.

Exact-source reproduction is the existing explicitly executed copy operation. Offspring preparation and admission do not run either parent or child. The website starts with a complete still scene and separate controls for gestures, social simulation, offspring preparation/admission and task Run. A user-triggered family demonstration advances the real world command protocol and commits actual children; the subsequent ceremony only displays committed events. Rendering, seeking, replaying or skipping a ceremony cannot create a child or execute a task.

## 2. Four closed offspring recipes

Parents are ordered roles with exact source identities and companion intent hashes (null when absent). Revalidate each source as the canonical complete constructor. For typed recipes, recompile stored IntentIR and compare its graph, excluding source-carried design, against the parent's source graph; recompute types rather than trusting submitted contracts. Compare full normalized structural types, including symbolic dimensions, record fields and optionality. L and mL are distinct; L*s*s^-1 normalizes to L. Refinements are checked again on the resulting child. Source-only recovery cannot invent missing units, thought or prior lineage.

- **compose:** one declared output of parent0 replaces one literal input of parent1. Import the donor's entire pure predecessor closure, rewrite all recipient uses/outputs, and prune unreachable recipient nodes. Require at least one surviving recipient operation and actual donor contribution. The two connected types must be exactly equal. This is an inspectable computation connection, not injection of a cached result.
- **mate:** the same substitution, with an explicitly selected donor node and recipient node rather than requiring output-to-literal ports. Donor closure must be pure. The recipient's action nodes and every ancestor of each direct Boolean guard are protected from replacement. Every original recipient action must survive pruning with its action name, allowed flag and guard cone unchanged under the namespace map. Payload computation can change if its exact type fits. Reject whole-task replacement and eager action branches.
- **merge:** retain both complete parent DAGs in separate namespaces, preserve ordered ports/guards, and add one report with ordered labels a0..aN then b0..bN for every declared output. At most 16 report inputs (the combined declared parent outputs) and 64 total child nodes including the report. Merge preserves unlike dimensions in separate record fields; it does not average or convert them, optimize a joint objective, or consume the parents. Simulated actions remain guarded and only run on explicit child Run.
- **body:** retain the chosen base parent's exact task projection and repeats, while recombining source-authored style. Metadata-free sources are eligible. This is body-only inheritance, not a new computation; supplied companion task metadata is retained where available.

All generated child node IDs use role/index names from a stable topological ordering with original node order breaking ready-node ties. Repeated input ports and output order survive. Child node origins identify parent/parentNode or explicitly generated report nodes. Source maps use mechanically generated clauses, never fabricated English spans. Task recipes use repeats1; body retains base repeats. Names and companion descriptions are bounded generated text. No callbacks, new evaluator, source-string crossover, arbitrary field mutation, provider credentials or parent run records occur.

Self-pairing of a resident is forbidden. Task recipes reject equal-source parents; distinct residents with equal source can hang out and use body inheritance, which is explicitly labeled same-source variation. Manual body variation with repeated source references is also labeled variation rather than evidence of two distinct biological parents.

## 3. Bounded source-authored heredity

Add optional design.heredity, closed and independently validated:

```
{model:'bounded-traits-experimental', parents:[hashA,hashB],
 seedDigest:64-lowercase-hex, nonce:uint32,
 traits:{elongation,spread,curvature,gestureGain,tempo,pigmentGain}}
```

Each trait is an integer in[-1000,1000]. Parents are two complete-source SHA256 hex digests, never embedded parent programs. Resolved anatomy and motion remain in source. Parent assertions are not authenticated lineage; recovering source retains these asserted hashes/traits but does not reconstruct the external derivation or original typed interpretation. The child does not embed its own hash.

Parent traits come from authored heredity if present. Otherwise derive a labeled legacy-phenotype vector from fixed source controls: let e be root axial length (chamber2*axesY or spine length), r be root transverse size (chamber2*sqrt(axesX*axesZ) or radii0+radii1), and b be mean spine bendX or0. Use clamp[-1000,1000] of round(1000*(e/r-1.5)/1.5) for elongation, round(1000*(r/e-.6)/.6) for spread, round(5000*b) for curvature, round(1000*(gestureStrength-.65)/.35), round(1000*(phaseRate-.038)/.007), and round(1000*((chromaStrength??0)-.85)/.1). These are explicit phenotype measurements, not recovered historical alleles.

Seed digest is SHA256 of UTF8 canonical JSON containing a domain prefix, ordered exact parent source/intent hashes, complete recipe/style/nonce and compiler/assembly/heredity policy identifiers. The first four bytes big-endian seed Anatomy.generate. Named hash draws select A, B or floor((A+B)/2) independently for each trait. Gentle mutation affects at most two distinct loci with integer signed deltas of magnitude1..80, then saturates; record actual changes, and do not call the draws unbiased. Optional explicit full trait overrides are validated authoring inputs, never arbitrary paths. No ambient randomness, wall time or task results participate.

Generate topology/owners from the new graph first. Apply elongation as axial scale1+.12*g, spread as radial scale1+.10*g, curvature as bendX+.025*g, gestureStrength+.10*g, phaseRate=.038+.007*g, chromaStrength=.85+.10*g, where g=trait/1000. Clamp to existing field domains, quantize resolved authoring values to1e-6 using Math.round, normalize negative zero, then validate assembly/tree/owners/gesture/QDL and complete source≤65536UTF8 bytes. Hinge topology and owner partitions are unchanged by trait application. Preserve role colors of actual child operations. Drop incompatible inherited scalar lenses with a diagnostic; child records/lens values are never inherited.

Compare normalized executable DAG+ordered outputs+repeats separately from resolved visual design, excluding graph names, node spelling and heredity assertions. Return sourceChanged/taskSyntaxChanged/bodyChanged and classification. Refuse a candidate that changes neither task nor resolved body; different hashes alone do not establish novelty. Structural changes do not prove different behavior for all inputs. One request builds one candidate; no hidden novelty search.

## 4. Social world and lifecycle

One world per Runtime, maximum32 residents including8 nursery;16 disjoint pairs; at most16 live proposals, because each parent can have only one unresolved proposal;256 informational events with dropped count. World ticks0..1000000 at an optional20Hz controller, commands/revisions/epochs bounded and never wrapping. Artifact IDs, resident IDs, candidate IDs, derivation IDs and execution IDs are distinct. Resident IDs are world-scoped monotonic admission IDs. Identical-source residents remain separate individuals.

Arena512×320 integer coordinates, guard half-width24, boundary inset24. Admission uses a finite deterministic spawn list. Rank eight unit moves plus waiting by integer goal distance, local crowd and heading penalties. Rotate ID-ordered priority each tick. A movement's swept guard box must be disjoint from every other old guard and accepted swept box; waiting is available. Display every full gesture envelope within its guard, using conservative portrait bounds. Straight interpolation stays inside the swept box; no overshooting spline or collision/fairness claim beyond this reservation rule. Open clearings and bounded timeouts handle jams.

Structural affinity (operation-role overlap, gesture kind, diversity, distance) is a visible bounded heuristic, never English understanding or typed compatibility. Provide neutral affinity mode. Invitations require active enabled adults, energy≥60, no rest/cooldown/partner/pending proposal. Reciprocal invitations are resolved on one common snapshot into disjoint pairs; reserve two distinct free rendezvous slots. Invitation expires120 ticks; approach timeout160; court requires80 consecutive arrived ticks; proposal expires600 ticks, with validity tick<expiry. Withdrawal/removal cancels both pair references and pending proposals atomically, increments policy epoch, and cannot be undone by re-enabling. No proposal implies a child.

Energy is artificial simulation data in0..100. Each20 ticks, nursery/rest +4; paired approach/court -2; unpaired roam/invite -1; cooldown +2, all saturated. Below20 sets rest latch and cancels pair/proposal; at≥60 clears it. New child has energy40, nursery for200 ticks, pairing disabled, no record and no inherited authority. Imported adults start60, pairing disabled. Pair enablement is a local scenario setting, not an assertion of creature consent. Birth costs30 each parent after both still have≥50; cooldown200. Birth/maturation/expiry deadlines must fit tick ceiling, while abort cooldown may saturate to it.

Step order: explicit commands; tick increment; maturation; energy/latch; expiry/withdrawal checks; reciprocal pairing; reserved movement; dwell/proposal. Body phase and render cadence do not enter state decisions. Hidden tabs pause without catch-up; at most4 explicit ticks per controller batch. Inspect/view/preview do not tick. World simulation never calls the task interpreter. Birth remains an explicit admission command; a labeled family-demo button is an explicit sequence of such commands, not an animation callback.

## 5. Pure preview, atomic admission and bounded evidence

Offspring preview is stateless: it writes no artifact/world/lineage/candidate/run stores. Website retains at most8 previews. Candidate≤2MiB includes source/typed companion/genomes, lineage≤32KiB and≤64 node-origin rows. Parent/version/style pins and recipe determine candidate ID; derivation ID additionally binds child source. Use standard SHA256 implementations or independently check a shared synchronous implementation against platform crypto and published vectors. Custom Q.canon is not advertised as RFC8785 compliance.

Admission receives input, candidateId, childSourceHash, target and requestId; rebuilds and compares all pins rather than trusting uploaded candidate blobs. Target library permits manual recipes; target world requires a fresh matching social proposal and exact parent resident/source/companion/policy epochs. Successful request lookup precedes freshness checks: same key/same canonical payload returns original acknowledgement; same key/different payload refuses. Maximum128 derivations and128 successful admission receipts retained for the session; full ledgers reject rather than evict replay protection. Distinct derivations may identify one source without replacing stored companion metadata.

Validate and stage ALL state before mutation: exact parents, recipe/compiler identity, proposal validity/membership/participation/energy; world revision; nursery/resident/spawn/timer bounds; source/companion conflict; artifact/lineage/receipt count and aggregate bytes; and bounded response. Stage artifact materialization without enriching existing metadata. Commit artifact, derivation, child resident, nursery designation, both charges, cooldown/latch changes, proposal consumption/pending links and request result in one synchronous transaction with no intervening await. No checks/serialization that can normally fail remain after commit. Rejection preserves every authoritative store/counter and parent charge. In-memory atomicity is not crash durability.

Artifact store has existing count caps plus32MiB aggregate serialized artifact budget, including genomes/companions. World snapshot≤1MiB, lineage store≤4MiB, admission acknowledgements≤4KiB. Successful admission adds no execution record; record capacity is irrelevant. Command receipts use a256-entry bounded window; older sequences refuse as stale, never execute again. Mutation sequence/counters stop at1000000. Preview cancellation never admits anything; synchronous evaluation/commit is not preemptible. Transport loss after commit is resolved by the explicit idempotency key.

## 6. Library and adapters

Extend Runtime additively, preserving the eight shipped methods/operations and their semantics. Add strict discriminated request/result types for offspringPreview, offspringFrame, offspringAdmit, lineage, annotate, worldCreate, worldInspect, worldCommand. Preview status ready/rejected carries either a full candidate or diagnostics. Admission returns small IDs/placement acknowledgement. worldCommand supports import, retire, participate, invite, cancelProposal, advance1..4, with expectedRevision and sequence; each successful mutation advances revision once and duplicate matching sequence returns saved acknowledgement. worldCreate is idempotent by worldKey+seed; different configuration conflicts, additional world requires another Runtime. annotate recompiles a supplied IntentIR against exact source graph and attaches only absent/identical metadata, never fictional recovered authorship.

Parent reference is {artifactId,intentHash:string|null}. Recipe union is {kind:'compose',donorOutput,recipientInput}, {kind:'mate',donorNode,replaceNode}, {kind:'merge'}, or {kind:'body',base:0|1}. Offspring input also has required nonce, style:{mutation:'none'|'gentle',traits?:completeSixTraits}, and origin:{kind:'manual'} or {kind:'pairing',worldId,proposalId,parentResidents:[idA,idB],epochs:[epochA,epochB]}. Targets are {kind:'library'} or {kind:'world',worldId,expectedRevision}. Unknown fields are rejected recursively. Origins/target must agree; manual input cannot bypass world birth policy by admission as a child.

MCP adds eight quineling_* tools matching the new operation names, complete actual discovery schemas and structured errors; original eight names stay. Preview/frame/lineage/worldInspect are read-only; mutation tools are not; idempotency is tied to explicit keys. worldCommand is potentially destructive because it retires residents/cancels proposals. Preserve request/response caps and pre-dispatch cancellation. A2A accepts the extended structured operation union and retains text→passive create and {operation,result} artifact envelopes, scoped bounded task lifecycle and error fields. Agent card adds ranch build/social skills; only run/reproduce evaluate tasks. No unnecessary second envelope/version freeze. World mutation is not task execution.
