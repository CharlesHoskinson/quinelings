# Pure offspring implementation

Implemented `offspring.js` as a UMD/CommonJS module with `POLICIES`, `TRAITS`, `validateInput`, `intentHash`, and `build`. The public construction key and SHA256 domain separation follow `docs/RANCH-INTERFACES.md`. Root's integration correction additionally binds `origin` in the derivation ID digest, while the candidate ID, seed and child source remain origin-independent; different social births of the same construction therefore retain distinct derivations. `build` returns a detached candidate directly or throws an error with `code`, `message`, and `path`. No stores, clocks, callbacks, interpreter invocations, action evaluations, or execution records participate.

Parent sources must be canonical complete task constructors. Validation reconstructs the shared constructor and compares exact source; supplied typed companions are independently recompiled and compared with the complete task projection. Stored contracts are never used as type evidence. Body retains the base graph name, IDs, order, parameters, ports, outputs, repeat count, IntentIR, compiled contract, and source map. Source-only assembled parents can use body inheritance, with absent metadata retained as absent. Old non-assembly sources refuse `missing-anatomy`: the published phenotype measurement has no root controls to read, and the SDK already requires assembly anatomy. No missing historical traits or units are inferred.

Compose/mate import a pure predecessor closure, rewrite every matching input/output reference, prune recipient predecessors that no longer contribute, protect every original action and all transitive guard predecessors before and after rewriting, and require an actual donor-to-original-recipient-operation-to-output connection. Generated role IDs are `p0n<topological index>` and `p1n<topological index>`; ready ties follow original node order. Ordered repeated ports survive. Merge retains both DAGs and creates `report`, with labels `a0..` then `b0..`; combined outputs and total node limits are checked. Every task child is recompiled, including pure compile-time refinement evaluation. Source maps are the compiler's mechanical clauses.

Every recipe starts from `Anatomy.generate(childGraph, firstFourSeedBytesBigEndian)`. Trait inheritance uses named SHA256 draws `trait:<traitName>`, `mutation:locus:0`, `mutation:locus:1`, and `mutation:delta:0/1`, with the prescribed modulo selection, floor midpoint, signed mutation magnitudes, saturation, and recorded actual changes. Explicit six-trait overrides bypass draws. Parent measurements are labeled `legacy-phenotype` or `authored-heredity`; overridden traits are labeled in derivation metadata. Trait changes are clamped to existing physical authoring domains and rounded to six decimal places. Owners/hinges stay unchanged. Incompatible inherited scalar lenses are dropped with a diagnostic. Strict bounded heredity assertions are embedded in the constructor design.

Change flags compare against recipient role 1 for task recipes and the selected base for body. Task comparison normalizes node spelling/name, preserves ordered ports/outputs, and includes repeats. Body comparison ignores heredity assertions, assembly seed/compiler metadata, and mechanically renamed owner node IDs. Neither task nor resolved body changing refuses `no-novelty`, even when source hashes differ. Structural change is not a claim of different results for every input. Candidate lineage retains the complete construction input, policy identifiers, ordered origin rows, seam, draws, and mutation changes. Derivation and candidate byte caps apply before returning.
