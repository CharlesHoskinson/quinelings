## Contracts retained

These are demonstrated boundaries, not silently replaced semantics: JavaScript floating point; equal-cost neighbor-ordered BFS; full-request-or-zero sale quotes; hunger as a positive guard; unauthenticated source labels and caller-supplied freshness; unlimited-parallel dependency estimates; local simulated action receipts. Decimal, empty/zero, constrained-material, conflicting-provenance, guarded-action and scheduling presets make these visible. Exact-decimal arithmetic, worker reservations, authenticated witnesses or external City operations would be new language/application capabilities requiring their own design and acceptance evidence.

The QDL 1 registry, frozen recipe sources, release tag and retained SDK archive are unchanged. New food/retry/water programs and experimental offspring are new sources. The website model uses abstract identity tokens and bounded randomized traces; it is not a proof of the browser, cryptographic hashes, floating arithmetic or renderer.
