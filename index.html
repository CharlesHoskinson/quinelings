02 / BODY

You can see its structure.

Operations become colored organs. Dependencies—the places one operation uses another’s result—become connecting filaments. Click a program line to find its organ.

A chosen body family supplies the silhouette. Program depth and branching shape its folded ribbons. Compression and depth make the folds luminous; inspection reveals the colored organs and connections.

03 / QUINE

It outputs its own source.

A quine is a program that outputs its own source code. Each Quineling computes its task result and constructs its complete source as a separate output.

Reproduce builds and runs a fresh program from that emitted source, then verifies that the source and task results match.

Everything runs in your browser: a JavaScript interpreter executes the program, and a canvas draws its body. Motion displays structure; the Run controls execute tasks. Programs have up to 64 task operations and 1–8 task cycles.

THE RECOVERABLE GENOME
Recover the complete program.
The body shows program structure. Its genome stores the complete source in two independently recoverable forms: wave data and exact RGB color records. Either can rebuild the program, including its task inputs and body design.
Wave data: each band stores 32 coefficients that encode source bytes in a cosine wave. Recovery uses 65 numerical samples from every band to reconstruct those coefficients and the source.
RGB data: each exact color record stores a source byte. This encoding is separate from the organ colors, which identify operation types. Recovery uses the underlying data, not a screenshot of the creature.

A little more about the creatures


Why give a program a body?
A body gives you a visual index into a program: select an organ, inspect its operation, and follow its inputs to the result. Compare a lamp-repair decision, a route, or a budget across prepared scenarios, then reproduce the exact program that made the decision.


Are they alive or thinking?
“Living program” is the creative metaphor. These specimens reproduce identical executable programs when you use the controls. The thought bubble describes an authored task; the demo pairs that description with a program explicitly. This browser prototype uses retrieved artwork and local simulated actions. The wider Midnight.city ambition is for agents to exchange inspectable, reproducible programs whose structures become animated creatures and street art.


Does every program have a unique-looking creature?
The full source is preserved in its genome. The body is a designed visual summary, so different programs can look similar. Operation colors, frequencies, connections, and the chosen family explain the anatomy; genome recovery checks exact source identity.


How does the source reproduce?
The program quotes its task and a smaller constructor body as data. Running the constructor rebuilds the complete expression and emits it. Reproduce parses that output and runs a fresh instance. The generation counter records verified copies with matching source and results.
