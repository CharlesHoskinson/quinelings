ONE SOURCE · A TASK AND A BODY

Create, then run.

import { Runtime } from '@quinelings/agent-sdk';

const runtime = new Runtime();
const created = runtime.create('[2,3,4] | square | sum | report total');

if (created.status === 'supported') {
  const record = runtime.run(created.artifact.id);
  // Task output: [{ total: 29 }]
  const child = runtime.reproduce(created.artifact.id, record.id);
  // Fresh execution. Exactly the same emitted source.
}

Create and compile check typed data and construct the body without running the task. A successful Run records its result against this source. Reproduce uses a specific parent record and explicitly executes a fresh copy. Current actions produce local simulated receipts.

What is established?

The runtime verifies exact source reconstruction and genome recovery. Lean checks the published mathematical lemmas; Quint explores lifecycle transitions. Browser tests check the implementation’s behavior. Those are separate kinds of evidence: neither model proves arbitrary English meaning, visual beauty or the entire JavaScript renderer.
