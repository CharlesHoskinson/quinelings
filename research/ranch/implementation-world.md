# Pure world implementation evidence

Implemented against RANCH-INTERFACES.md and all resolved candidate audits. This is an experimental deterministic in-memory lifecycle; it does not choose offspring recipes, create constructor source, evaluate tasks, persist crash-durable transactions, or authenticate ancestry. Runtime owns artifact preparation, aggregate storage, derivation and admission-request acknowledgements.

## Exact state and identity

`ranch-world.js` exports UMD global `QuinelingWorld` / CommonJS `LIMITS`, `SPAWNS`, `CLEARINGS`, `create`, `command`, `admit`, `annotate`, `validate`. Browser SHA dependency is `RanchCrypto`, supplied by root's `ranch-crypto.js`. All context data is detached `{artifact:{id,sourceHash,intentHash,roles,gestureKind}}`; no callback is accepted. Other commands require an empty context. World residents retain only bounded structural labels and exact artifact/source/intent pins.

Root approved additive `affinity:'structural'|'neutral'` WorldCreate configuration. Omitted means structural; identity hashes normalized `{worldKey,seed,affinity}`. Default and explicit structural configurations agree. World snapshot includes affinity. Neutral mode ranks distance alone. This is a public interface addition to be reflected in root-owned documentation and adapters.

`pairs` and `proposals` are arrays. Pair is `{id,parentResidents,slots,startTick,approachDeadline,attemptDeadline,dwell,arrived}`. Proposal is `{id,parentResidents,artifactIds,sourceHashes,intentHashes,epochs,createdTick,expiry}`. Invitation is `{partnerId,expiry}` or null; partner is resident ID or null; pendingProposal is proposal ID or null. Nursery flag is `nurseryUntil>0`, set to zero at maturity. `readyAfterTick` is cooldown; pending and cooldown are independent.

Command result is `{worldId,revision,sequence,tick,residentId?,proposalId?,appliedTicks?}`. Admission result is `{worldId,revision,tick,residentId,parentResidents}`. Annotation result is `{worldId,revision,tick}`. All transitions return detached `{world,result}`. Rejected preparation leaves original input deeply unchanged. Plain-data validation rejects accessors without evaluating them, cycles, hidden/symbol fields, custom prototypes, sparse/custom-field arrays and unknown record fields. Errors carry `.code`, `.message`, `.path`; codes are invalid-input, invalid-world, capacity, not-found, sequence, conflict, stale and ineligible.

## Deterministic affinity, insertion and movement

Spawn order starts with ten framing positions: (120,24), (168,24), (344,24), (392,24), (24,144), (72,144), (440,144), (488,144), (168,296), (344,296). It then appends the 60-point row-major grid `x=24+48*(i%10)`, `y=24+48*floor(i/10)`, i=0..59, excluding duplicates, for 68 distinct positions. First position whose guard avoids every actual resident and live reservation wins. Population remains capped at32, nursery8. Clearings in fixed order are [(120,96),(168,96)], [(344,96),(392,96)], [(120,224),(168,224)], [(344,224),(392,224)]. Pair parent order is ascending numeric resident ID. Select the first clearing with both slots free under the explicit pair-parent exception and both parent Chebyshev distances <=160.

Structural affinity is `8*uniqueRoleIntersection + 4*equalGestureKind + 2*differentSourceHash - ChebyshevDistance`; neutral affinity is `-ChebyshevDistance`. Ties use ascending numeric resident ID. It is a bounded structural/distance heuristic and does not check task types or imply compatibility. Eligible adults without an invitation choose a candidate deterministically. After all invitations are present, reciprocal invitations are read from one common snapshot into disjoint pairs. Pair creation clears invitation timers.

Enabled, nonrest adults without a pair roam toward spawn index `(seed%SPAWNS.length + numericResidentId*7 + floor(tick/80)*11)%SPAWNS.length`. Disabled/rest/nursery residents wait. Paired residents target their reserved slot. Fixed move enumeration is wait,E,SE,S,SW,W,NW,N,NE. Moves rank lexicographically by Chebyshev goal distance, Manhattan goal distance, count of other old guards with centers at Chebyshev distance<96, heading difference, enumeration index. Heading is last nonwait enumeration index; wait has heading penalty0. Nonwait penalty is `min(abs(index-heading),8-abs(index-heading))`. Heading0 is the initial neutral value. Numeric-ID move priority rotates left by `tick%residentCount`.

Each accepted movement's axis-aligned endpoint union expanded24 must be inside the arena and strictly disjoint from every other old guard and previously accepted swept union. Touching edges are legal. Reservations are also respected; paired movers have the explicit exception for both slots of their own pair. This exception allows approach past a partner's unoccupied reservation; actual and swept guards never receive that exception. Waiting retains the old valid guard. These are discrete conservative collision checks, not an obstruction or congestion fairness proof.

## Timers, energy and admission

Tick phase is increment, maturity, priority energy/rest, expiry, automatic invitations/reciprocity, movement, dwell/proposal. Energy each20 ticks uses nursery/rest +4 before pair -2 before cooldown +2 before adult roam/invite -1. Values clamp0..100. Below20 sets rest and cancels pair/proposal; >=60 clears rest. At the exact maturation tick the nursery flag clears before that tick's energy row.

Approach deadline start+160 and attempt deadline start+240 are immutable. Expiry precedes movement/dwell. Arrival permanently disables the approach-only timeout; dwell resets on absence but never resets the overall deadline. First arrived tick counts1; court80 creates a proposal, releases pair/reservations and sets cooldown200. Proposal expiry600 is half-open. Pending links allow cooldown recovery and block new invitations.

Admission rechecks revision and exact live ordered proposal pins, enabled adulthood/rest/energy>=50, capacity, geometry, child identity and all deadlines. It consumes once, charges30 to each parent, inserts disabled nursery energy40 for200, and advances revision once. Successful admissions have no world-command sequence; Runtime retains their complete request acknowledgements. A consumed proposal cannot produce a second child under a different request key. Annotation invalidates every changed resident pin/epoch and its pair/proposal in one revision. Identical annotation is unchanged.

Receipt payload hash is SHA256(Q.canon(complete WorldCommand)). Exact retained replay precedes revision and ceiling freshness, returns original acknowledgement and changes nothing. Conflicts, sequence gaps and discarded stale sequences reject. Window256 evicts acknowledgement bodies without decreasing nextSequence. New commands stage all1..4 ticks with one revision; no counter wraps past1e6. Import, withdrawal and other safe management can work at frozen tick ceiling if their own counters permit. Any new deadline that must fit is preflighted; abort/unilateral cooldowns saturate.
