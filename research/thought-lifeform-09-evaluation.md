# Workstream 09: evaluation from thought to new beautiful creature

Reviewed generation/formal/semantic/anatomy/lifeform and graphics proposals and current interpreter, morphology, chroma and browser tests. Separate six claims: accepting text, adequate task interpretation, correct execution, genuinely generated anatomy, exact source reproduction, and beautiful accessible presentation. Passing the later tests does not establish the earlier ones. Current manually elaborated examples demonstrate kernels/quine/codec behavior, not an automatic natural-language compiler or a new compositional body generator.

## Benchmark and independent oracles

`thought-lifeform-09-benchmark.json` contains 20 concrete thoughts: 10 supported, 4 clarify, 3 unsupported and 3 inconsistent. The labels reflect today's actual capabilities and stated inputs. A future system may support more cases only after registry/runtime semantics are extended. An optional partial proposal is allowed for unsupported cases, but cannot be counted as successful full execution. Normalize internal `compiled`/`supported` and `needs-information`/`clarify` to these benchmark labels; do not allow inconsistent outcomes to masquerade as generic unsupported capability.

The ten supported thoughts include five familiar reductions/plans and five composition holdouts. Every expected result is a literal independently specified oracle (including duplicate policy, tie/source provenance and FIFO semantics), not output compared with itself. `thought-lifeform-09-oracles.cjs` runs their current kernel operation sequences and proves these data cases are executable today. It additionally confirms zero-weight and cyclic-schedule rejection. Results are recorded in JSON. This is an interpreter baseline; it does not report classifier accuracy or natural-language compilation success.

For an eventual synthesizer, expose only familiar recipes in its examples. Freeze holdout text and expected outputs before prompt/model/compiler tuning. Add two paraphrases per thought and at least three input variations per supported case. Outcome equality, not textual AST equality, is the first semantic test. Require every generated plan to disclose assumptions and input origins. Matching a template's goal keyword is not compositional coverage: held-out cases must join operations in an ordering/dependency combination absent from provided recipes. Maintain a larger independently written unseen corpus before claims beyond this small controlled benchmark.

## Release gates

1. **Meaning and capability adequacy:** all 20 baseline status cases correctly resolved, all supported exact results pass, no unsupported/inconsistent request silently executes, and clarification preserves unresolved requirements. Five composition holdouts must compile without a corresponding whole-plan template. Record raw/proposed IR, compiler diagnostics and resulting executable source for inspection. Human review checks original thought against interpreted constraints; no claim of universal English equivalence.
2. **Task execution:** all existing fixtures plus new compiler fixtures pass; unit/type/port/refinement failures rejected or explicitly surfaced. Effects need their own guards; simulated actions stay simulated. Positive and negative outcomes are independently specified. No default observations, fairness policy, deleted constraints or invented authority.
3. **Graph novelty:** report normalized semantic graph signatures containing operation IDs, ordered ports, literal/parameter semantics and graph connectivity, not names or display seed. The five compositional holdouts must not merely equal a catalog graph after identifier renaming. A shape recolor/new title is not a new program. If semantically equivalent optimization changes representation, maintain a normalized policy and explain its equivalence rather than equate byte novelty with useful novelty.
4. **Generated anatomy:** for at least five different novel task graphs, compile the body grammar into deterministic material recipes outside ten mandatory skin choices. Same graph/design/generator identity/seed gives the same material recipe; changing seed changes only bounded anatomy, not task outcome. Require graph structure changes to visibly affect coarse anatomy, rather than seed noise doing all differentiation. Resource counts and source-linked ownership remain correct. These gates are proposed; current family demos do not satisfy them yet.
5. **Identity:** three fresh interpreter generations emit the exact original canonical complete AST/design; both full harmonic samples and RGB records independently recover the source. Generated recipe identity and equal-phase material coordinates are checked separately. Mutation negatives must reject bad source checksums, corrupt emitted programs and stale traces. Existing quine equality is necessary but can faithfully reproduce an incorrect task.
6. **Beautiful accessible presentation:** pass explicit human film/thumbnail review and bounded browser behavior below. Numerical safety cannot prove beauty; automated image measurements diagnose failures and do not replace judgment.

Treat these as separate reported dimensions, never aggregate them into one opaque "alive" score. Zero false execution on unsupported/ambiguous thoughts is a release blocker; aesthetic scores cannot compensate.

## Critical adversarial tests

**Eager actions:** build a graph with `choose(false, action(true,...), harmlessValue)`. The current evaluator still runs the action producer. Compiler must reject this as conditional-effect lowering or produce an explicitly guarded action node; no test should pretend current `choose` is lazy. With guard=false, exact simulated receipt status is skipped and effects count zero. Trace replay, motion, lens changes and body picking keep execution/effect counters unchanged.

**Scalar state:** actual recorded zero displays zero; no trace is not-evaluated; missing node/path and nonnumeric Boolean/string/null are invalid; changed source marks old record stale; below/above-domain values preserve original number and explicit clipping labels. Independent tests check fixed units/domain and owners through deformation. Role color, scalar values and RGB genome remain separate encodings.

**Generated attachments:** every material assembly is rooted/connected under the grammar; body links are distinct from task edges; every operation is inspectable. Root/rim/hinge positions agree through ≥12 sampled phases and extreme allowed controls. Dependency endpoint pinning and ordered port labels remain exact. Reject degenerate spines/frames rather than silently substitute arbitrary normals. Caps and intentionally overlapping membranes have separate local/global geometry contracts.

**Temporal geometry:** periodic mode matches complete membrane/ownership/opacity/anatomy at t and t+period, including seam tangent/normal where regular; quasiperiodic drivers remain deterministic at random-access phases but show nonzero secondary differences after the fundamental cycle. A finite-phase test is empirical, not a global theorem. Frame-rate variants at 20/30/60/120Hz, long seek, pause and reduced-motion stills preserve source and meaning.

**Frame clear/render style:** repeated painting at a fixed phase gives identical pixels when the canvas is cleared. Rendering A then B must equal rendering B into a clean surface, detecting accidental accumulating trails or leaked context state. Existing reference style depends on within-frame density, not history. Particle tiers should preserve exposure through declared weights; compare silhouette, role hue and mean luminance across DPR/tier with calibrated tolerance. Literal exact pixels across CPU/GPU/platforms are not promised.

**Ceilings:** test exact lower/upper limits and one beyond: graph64/65 nodes, arrays512/513, input/output16/17, repeat8/9, bytes65536/+1, optional grammar16/17parts, attachmentdepth4/5, fanout4/5, particles24000/+1 and totalcrest1806/+1. Final wrapped source must also obey its genome budget. A valid small graph can exceed genome capacity once design is added. Adaptive sampling budget exhaustion reports degraded tolerance rather than claiming the requested chord error was met.

## Diversity and beauty review

Produce a fixed contact sheet: five novel graph structures × three seeds × four phases; add motion films ≥10 seconds for all five default seeds. Include existing specimen examples as context, never as the entire diversity proof. Present neutral grayscale/pearl and role-color views at 64,96,160 CSS-pixel specimen heights. Use the same camera policy and ink/exposure controls so brightness cannot masquerade as new anatomy.

Two reviewers independently score: recognizable connected principal mass; clearly attached continuation; distinct coarse silhouette; coherent prepare/stroke/recovery; luminous hierarchy and negative space; stable role ownership. Each category 1–5 with a written failure description. Initial acceptance: median≥4 and no category below3 per default creature; revise thresholds after pilot images, not after seeing evaluation results. Require at least 8/10 unlabeled species matching after a labeled reference sheet where species identities are meaningful. Generated individuals need not each be named as new species: ask reviewers to distinguish structural groups versus seed variation, and inspect confusion matrices.

Automated supporting diagnostics: occupied bounding-box ratio, silhouette components and holes, coarse contour distance, low-resolution feature distances, connected crest lengths and near-white saturation fraction. Ignore diagram overlays when measuring body. Torus interior gap, coral branches and moth hinge must remain visible; >one connected component can be intentional fine fringe, so components alone cannot define failure. Proposed <2% near-white foreground is an exposure diagnostic from the graphics review, not a universal artistic rule. Do not increase randomness/folds merely to improve diversity distance.

## Browser performance and accessibility

Measure a declared browser/device/DPR over 300 warmed frames; log p50/p95 rendering time, total main-thread time, memory and failures. Target p95≤33ms for one visible portrait on a stated midrange reference device and ≤50ms on a stated mobile device; distinguish geometry from paint. Stress five visible previews plus selected portrait, scroll offscreen and confirm hidden work is suppressed. Repeated source swaps must not monotonically leak caches. Initial compiler latency target ≤500ms excluding provider transport for these bounded fixtures; report failures/timeouts separately from provider latency. These are release budgets, not measurements already achieved by the proposed compiler.

Keyboard-only users can submit/clarify a thought, run, inspect owner/operation/result, pause and reproduce. All essential meaning appears as text, never color/motion only. At reduced motion choose a complete readable rest pose with unchanged node/result access; no autoplay task execution. Check 390px mobile width, zoom200%, focus visibility, touch selection and screen-reader announcements for capability status and actual receipts. A canvas aria-label alone does not expose 64 operation meanings.

## Evidence already available and remaining work

Existing test suites cover interpreter fixtures, canonical quines/codecs, sampled morphology/seams/resources, scalar states, local browser translation and no-motion execution. The generation report adds a manually lowered novel planters graph; semantics adds route/queue examples. This review adds ten independent numeric/algorithm oracles and a20-thought status benchmark. New automatic synthesis, registry typing, compositional anatomy, human scores and target-device timings remain unmeasured. Implement the evaluator harness before tuning a generator so a successful demonstration cannot redefine its own expected result afterward.
