What does “Living Thoughts” mean?

The “thought” is the author’s public description of a task. The source declares a finite, typed graph: each operation accepts specified kinds of input and passes its result along the connections. The same source assigns regions of the body to operations. Select one to locate its tissue and inspect its connections.

The calculation runs locally, and any action receipts are simulations. The public description is not a window into a model’s private reasoning. Animation gives the creature a living appearance; it has no awareness or independent intentions.

Why give a program a body?

The calculations use familiar methods, including sums and shortest-path search. The experiment joins a runnable task with an inspectable body in one source that can reconstruct itself. The body helps you find an operation; the run record shows what it computed. Exact identity comes from source bytes, since different programs can look alike.
