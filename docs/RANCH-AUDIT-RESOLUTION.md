R3/R4/R5/R13: existing kernels and the examples specialist's executable fixture already characterize the requested mean/budget, weightedMean and false-guard payload outputs. Array types contain element types, not dependent length indices. Symbolic dimensions means symbolic units. Preserve exact normalized structural types and independently recheck cardinality/mass refinements; do not add casts. Freeze concrete fixture sources/selectors and handwritten outcomes during implementation. Preserve nested merge fields and ordered inputs/outputs; disclose units in companion inspection, since raw results remain JSON numbers.

This creates a new complete task; it does not claim to preserve every parent execution schedule. Body retains exact base repeats. Changing merge evaluator semantics or adding per-namespace repeats is outside the closed recipe design.

R7/R8: require at most64 nodes in every recipe with exactly one origin row each. Accept strict source/companion graph equality and conflict rejection already intended; body exemption must preserve its exact task.
