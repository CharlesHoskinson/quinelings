# Fractal relief and strange-loop extensions

The implementation below adds escape-potential relief to `recursive-julia`, preserves contractivity in `recursive-affine`, and exposes a separate `WovenBody.strangeLoop(body, phase, opts)` sampler. It follows the supplied interfaces; integration points are proposed because the source files are unavailable.

Two mathematical distinctions matter:

- Quaternion squaring is not complex holomorphic. Its derivative must be propagated as a real linear map.
- Bicomplex dynamics admit two ordinary complex channels, so analytic derivatives and Douady–Hubbard potentials can be computed separately in those channels.

Use **bicomplex dynamics as the default mathematical foundation**, with quaternion slices as an optional visual variant.

## 1. Escape potential, derivatives, and distance

For \(f_c(z)=z^2+c\), iterate

\[
z_{n+1}=z_n^2+c,\qquad z_0=z,
\]

and differentiate with respect to the initial point:

\[
w_0=1,\qquad w_{n+1}=2z_nw_n.
\]

The escape potential is

\[
G_c(z)=\lim_{n\to\infty}2^{-n}\log^+|z_n|,
\]

with finite approximation

\[
G_N=2^{-N}\log|z_N|,
\qquad
\nabla G_N
=
2^{-N}\left(
\Re\frac{w_N}{z_N},
-\Im\frac{w_N}{z_N}
\right).
\]

The exterior distance estimator is

\[
\widehat d_N
=
\frac{G_N}{|\nabla G_N|}
=
\frac{|z_N|\log|z_N|}{|w_N|}.
\]

This is a local asymptotic estimator near suitable Julia boundary points, **not an exact distance or universal certified lower bound**. An orbit that has not escaped within the iteration budget is unresolved.

Choose an escape radius satisfying

\[
R>\frac{1+\sqrt{1+4|c|}}2.
\]

### Bicomplex three-dimensional slices

Let \(i^2=j^2=-1\), \(ij=ji\), and

\[
e_\pm=\frac{1\pm ij}{2}.
\]

For \(Z=a+bj\),

\[
Z=z_+e_++z_-e_-,
\qquad z_+=a-ib,\quad z_-=a+ib.
\]

Thus \(Z\mapsto Z^2+C\) splits into two complex quadratic maps.

A useful three-dimensional slice is

\[
a=x+iy,\qquad b=s,
\qquad z_\pm=x+i(y\mp s).
\]

Use the product escape potential

\[
G_B(x,y,s)=\max(G_+(z_+),G_-(z_-)).
\]

This maximum is nonsmooth where the two channel potentials coincide. Preserve it for dynamics; smooth it only when shading.

The channel distance estimates are distances in their respective complex planes. They are **not automatically distances in the three-dimensional slice**, whose embedding changes the metric.

### Quaternion option

For \(q_{n+1}=q_n^2+c\), a perturbation obeys

\[
\delta q_{n+1}=q_n\delta q_n+\delta q_nq_n.
\]

For a slice \(q_0=x+yi+sj\), propagate three tangent columns initialized to \(1,i,j\). Then

\[
\partial_\alpha G_N
=
2^{-N}
\frac{\langle q_N,\partial_\alpha q_N\rangle}{|q_N|^2}.
\]

The ratio \(G_N/|\nabla G_N|\) supplies a slice relief scale, without importing a complex Julia distance theorem.

## 2. Whitney fold and cusp amplification

Attach caustics to a local projection of the body surface:

\[
F_{A_2}(a,b)=(a,b^2),
\qquad
\det DF_{A_2}=2b,
\]

\[
F_{A_3}(a,b)=(a,b^3+ab),
\qquad
\det DF_{A_3}=3b^2+a.
\]

The cusp critical set is \(a=-3b^2\), whose image is

\[
(X,Y)=(-3b^2,-2b^3).
\]

Regularize the projection-density singularities:

\[
A_2=\frac{\varepsilon}
{\sqrt{(2b)^2+\varepsilon^2}},
\qquad
A_3=\frac{\varepsilon}
{\sqrt{(3b^2+a)^2+\varepsilon^2}}.
\]

Both remain bounded by one. Use them for ridge strength and bounded normal displacement. These are deliberately placed canonical caustic patches; identifying intrinsic caustics of the existing embedding would require its actual projection Jacobian.

## 3. Drop-in numerical helpers

The following dependency-free block can sit beside the existing Julia compiler.

```js
const FractalRelief = (() => {
  const clamp = (x, a, b) => Math.max(a, Math.min(b, x));

  // c = [real, imaginary]. Derivative is with respect to z0.
  function complex(x, y, c, opts = {}) {
    const maxIter = clamp(Math.floor(opts.maxIter ?? 96), 1, 512);
    const radius = Math.max(
      opts.radius ?? 16,
      1 + (1 + Math.sqrt(1 + 4 * Math.hypot(...c))) / 2
    );

    let wr = 1, wi = 0, n = 0;

    while (Math.hypot(x, y) <= radius && n < maxIter) {
      const nr = 2 * (x * wr - y * wi);
      const ni = 2 * (x * wi + y * wr);
      const nx = x * x - y * y + c[0];
      y = 2 * x * y + c[1];
      x = nx;
      wr = nr;
      wi = ni;
      n++;
    }

    const r = Math.hypot(x, y);
    if (!(r > radius) || !Number.isFinite(r)) {
      return {
        escaped: false, n, G: 0,
        gradient: [0, 0], distance: null
      };
    }

    const scale = 2 ** (-n);
    const r2 = r * r;
    const gx = scale * (wr * x + wi * y) / r2;
    const gy = -scale * (wi * x - wr * y) / r2;
    const G = scale * Math.log(r);
    const norm = Math.hypot(gx, gy);

    return {
      escaped: true, n, G,
      gradient: [gx, gy],
      distance: norm > 0 ? G / norm : null
    };
  }

  function bicomplex(x, y, s, cPlus, cMinus, opts) {
    const plus = complex(x, y - s, cPlus, opts);
    const minus = complex(x, y + s, cMinus, opts);
    const usePlus = plus.G >= minus.G;
    const active = usePlus ? plus : minus;
    const [gx, gy] = active.gradient;

    return {
      plus, minus,
      G: active.G,
      // One branch gradient of max(G+, G-).
      gradient: [gx, gy, usePlus ? -gy : gy],
      channelTie: Math.abs(plus.G - minus.G) < 1e-10
    };
  }

  function caustics(a, b, epsilon = 0.04) {
    const e = Math.max(1e-6, epsilon);
    return {
      fold: e / Math.hypot(2 * b, e),
      cusp: e / Math.hypot(3 * b * b + a, e)
    };
  }

  // p and normal are 3-vectors; a,b are local patch coordinates.
  function displace(p, normal, sample, a, b, opts = {}) {
    const { fold, cusp } = caustics(a, b, opts.epsilon);
    const potential = Math.log1p(
      Math.max(0, opts.potentialScale ?? 8) * sample.G
    );
    const caustic = 0.4 * fold + 0.6 * cusp;
    const height = (opts.height ?? 0.08) *
      Math.tanh(potential) * (1 + 0.5 * caustic);
    const length = Math.hypot(...normal) || 1;

    return {
      point: p.map((v, k) => v + height * normal[k] / length),
      ridge: caustic
    };
  }

  return { complex, bicomplex, caustics, displace };
})();
```

For `recursive-julia`, compile the two complex channels into the existing grid cache. Add potential, gradient, escape-status, and distance arrays; preserve marching-squares contours. Contour either a selected slice or a chosen positive equipotential \(G_B=g_0\). A finite escape mask alone does not locate the exact Julia boundary.

### Preserve the affine attractor

For each existing IFS branch,

\[
T_i(p)=A_ip+b_i,\qquad \|A_i\|_2\le\rho<1.
\]

Keep these maps unchanged. Evaluate potential relief **after** orbit generation:

\[
\widetilde p=p+h(p)n(p).
\]

This preserves the underlying contractive IFS construction. Adding nonlinear relief inside every branch would require a new Lipschitz bound; the existing contractivity claim would no longer suffice.

Use a cached strand normal or embedding normal for \(n(p)\). For Julia contours, their planar normal provides a natural starting frame.

## 4. Ouroboros Möbius–trefoil manifold

Use a closed trefoil centerline

\[
C(\theta)=
\begin{pmatrix}
(2+\cos3\theta)\cos2\theta\\
(2+\cos3\theta)\sin2\theta\\
\sin3\theta
\end{pmatrix}.
\]

With a periodic normal frame \(N,B\), define a Möbius ribbon:

\[
M(\theta,v)=C(\theta)+
v\left[
\cos(\theta/2)N(\theta)+
\sin(\theta/2)B(\theta)
\right].
\]

Its seam satisfies

\[
M(\theta+2\pi,v)=M(\theta,-v).
\]

The three sectors correspond to

\[
[0,\tfrac13):\mathrm{quote},\qquad
[\tfrac13,\tfrac23):\mathrm{run},\qquad
[\tfrac23,1):\mathrm{apply}.
\]

Orient the loop so its terminal sector carries the sink territory and its seam returns to the root territory.

### Traveling soliton pulses

For the normalized KdV equation

\[
u_t+6uu_x+u_{xxx}=0,
\]

the line soliton is

\[
u(x,t)=\frac c2
\operatorname{sech}^2\left[
\frac{\sqrt c}{2}(x-ct-x_0)
\right].
\]

A circular pulse obtained by wrapping this profile is a visual approximation, not an exact periodic KdV solution. Exact periodic KdV waves require cnoidal profiles.

For three independently traveling, sech-squared pulses, take

\[
P(s,t)=\sum_{j=0}^2
\operatorname{sech}^2
\left(
\frac{\operatorname{wrap}_{[-1/2,1/2)}
(s-\nu t-j/3)}{\sigma}
\right).
\]

Use \(P\) to modulate ribbon width or brightness. “Fixed point” should refer to a separate semantic feedback invariant, not to these traveling waves.

## 5. `WovenBody.strangeLoop`

This sampler returns explicit coordinates and metadata. Its four-float layout is **defined here** as `(x, y, z, pulse)`; adapt the fourth slot if the current renderer uses another convention.

```js
WovenBody.strangeLoop = function strangeLoop(body, phase, opts = {}) {
  const TAU = 2 * Math.PI;
  const budget = Math.max(12, Math.floor(opts.budget ?? 768));
  const points = new Float32Array(4 * budget);
  const owners = new Uint16Array(budget);
  const stages = new Uint8Array(budget);
  const territories = body.territories ?? [];

  // Defaults are provisional: pass graph-derived endpoint territories.
  const root = opts.rootTerritory ?? 0;
  const sink = opts.sinkTerritory ??
    Math.max(0, territories.length - 1);

  if (![root, sink].every(
    n => Number.isInteger(n) && n >= 0 && n <= 65535
  )) {
    throw new RangeError("Territory owner exceeds Uint16 range");
  }

  const width = Math.max(0, opts.width ?? 0.12);
  const scale = opts.scale ?? 0.3;
  const speed = opts.speed ?? 0.08;
  const sigma = Math.max(0.005, opts.sigma ?? 0.045);
  const wrap = x => x - Math.floor(x + 0.5);
  const cross = (a, b) => [
    a[1] * b[2] - a[2] * b[1],
    a[2] * b[0] - a[0] * b[2],
    a[0] * b[1] - a[1] * b[0]
  ];
  const unit = a => {
    const n = Math.hypot(...a);
    return a.map(x => x / n);
  };

  function geometry(s, v) {
    const t = TAU * s;
    const r = 2 + Math.cos(3 * t);
    const dr = -3 * Math.sin(3 * t);
    const C = [
      r * Math.cos(2 * t),
      r * Math.sin(2 * t),
      Math.sin(3 * t)
    ];
    const T = unit([
      dr * Math.cos(2 * t) - 2 * r * Math.sin(2 * t),
      dr * Math.sin(2 * t) + 2 * r * Math.cos(2 * t),
      3 * Math.cos(3 * t)
    ]);

    // This trefoil's xy tangent never vanishes because r >= 1.
    const N = unit([-T[1], T[0], 0]);
    const B = cross(T, N);
    const a = Math.cos(t / 2), b = Math.sin(t / 2);

    let pulse = 0;
    for (let j = 0; j < 3; j++) {
      const q = wrap(s - speed * phase - j / 3) / sigma;
      // Stable sech², including narrow pulses.
      const e = Math.exp(-Math.abs(q));
      pulse += 4 * e * e / ((1 + e * e) ** 2);
    }

    const w = width * v * (1 + 0.25 * pulse);
    return {
      p: C.map((x, k) => scale *
        (x + w * (a * N[k] + b * B[k]))),
      pulse
    };
  }

  for (let i = 0; i < budget; i++) {
    const s = i / budget;
    // Interleaved samples across the ribbon.
    const v = 2 * ((i * 0.6180339887498949) % 1) - 1;
    const { p, pulse } = geometry(s, v);
    points.set([p[0], p[1], p[2], pulse], 4 * i);
    stages[i] = Math.min(2, Math.floor(3 * s));
    owners[i] = stages[i] === 2 ? sink : root;
  }

  return {
    points, owners, stages,
    stageNames: ["quote", "run", "apply"],
    seam: {
      fromTerritory: sink,
      toTerritory: root,
      transverseSign: -1
    },
    // Enables exact seam checks and structured ribbon meshing.
    evaluate: geometry
  };
};
```

A renderer can draw these samples as particles. A ribbon mesh should instead sample a rectangular \((s,v)\) grid and join its final row to the first with the transverse index reversed.

The fallback territory ordering is only illustrative. Resolve root and sink from the graph’s actual execution semantics, especially when several terminal nodes exist.

## 6. Making the strange loop computational

The manifold makes feedback visible; executable self-reference requires a staged evaluator.

Define the feedback operator

\[
F(x)=
\operatorname{apply}
\left(
\operatorname{run}(\operatorname{quote}(x))
\right),
\]

with an explicit representation and type contract at every arrow. A semantic fixed point satisfies

\[
x^\ast\equiv F(x^\ast),
\]

where \(\equiv\) must be specified—source equality, normalized syntax equality, or observational equivalence.

Connect this to offspring seams by storing the donor node, recipient node, and integration node alongside the loop’s stage metadata. Do not introduce an unrestricted runtime graph cycle merely to render the return arc. Execute feedback through bounded staged steps; only label it a fixed point after checking the chosen equivalence.

Before integration, verify:

- \(c=0\), \(|z|>1\): \(G(z)=\log|z|\), with finite-difference agreement for its gradient.
- Bicomplex channels evolve independently under squaring.
- Affine branch matrices retain their original contraction bounds.
- `evaluate(1, v)` agrees with `evaluate(0, -v)` within floating-point tolerance.
- Root/sink ownership follows graph semantics, and each feedback stage satisfies its representation contract.

These changes provide mathematically grounded fractal relief and an explicit visual return manifold. Semantic quine closure remains a separately checkable property of `quote → run → apply`.
