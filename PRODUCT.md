# Product

<!-- impeccable:product-schema 1 -->

## Platform
web

## Users
Visitors with no programming background learning what Quinelings are; developers connecting agent tasks through the TypeScript SDK.

## Product Purpose
Living Thoughts: express explicit tasks as executable programs with mathematical bodies, inspect their calculations, recover their complete source, and construct related programs.

## Operating Context
Static browser website hosted on GitHub Pages. Examples use supplied local data and simulated actions. The creation tool recognizes bounded recipe syntax; the QDL 1 workspace accepts explicit typed declarations and separate inputs.

## Capabilities and Constraints
Source reconstruction, role-based body ownership, five mathematical constructions, explicit task execution, local Ranch offspring recipes, TypeScript SDK and opt-in MCP/A2A adapters. Animation does not execute a task. Preserve frozen QDL 1 and all runnable examples. No fabricated autonomy, intelligence, or mathematical beauty proofs.

## Brand Commitments
Quinelings. Tagline: Living Thoughts. Original moving mathematical artwork at localhost:8047/tweet-reference is the user's beauty reference. Diverse attractors, fractals and other forms must remain visible. User requested Impeccable for website layout and presentation, clear beginner explanations, and improved animation performance. No internal reports on the public website.

## Evidence on Hand
Executable tasks and fixtures, five generated artifacts, frozen releases, finite numerical models and narrowly scoped Lean proofs. Existing reference video retained locally.

## Product Principles
Explain terms at first use. Show an actual calculation before advanced APIs. Distinguish task inputs, source parameters, and view controls. Keep the mathematical creature visible and useful.
