## Supported scope

This delivery remains explicitly labeled a **v1 candidate**. It supplies deterministic local agent-task computation and simulations in a bounded, single-owner memory session. Durable storage, authenticated shared deployment, live City dispatch, automatic arbitrary-English interpretation, a universal future-version translator and physical-GPU performance guarantees are not shipped capabilities. The standard library and collaboration policies are separately documented. Stable release retention and the explicit upgrade path are specified in `QDL-V1-UPGRADES.md`; no stable release tag or npm publication is implied by a format field.

Acceptance evidence, package/browsers and publication status are recorded in `research/qdl-v1/acceptance.json` and the execution ledger. Read the implementation contract, SDK guide, recipe guide and upgrade policy for their exact boundaries.
